# Security policy

Do not include API keys, credentials, private source documents, or generated sensitive content in bug reports or commits.

For a security issue, use GitHub's private vulnerability reporting for this repository if it is enabled. Otherwise, contact the repository owner privately rather than opening a public issue with exploit details. Provide the affected version, Python version, operating system, and a minimal non-sensitive reproduction when possible.

The XML parser disables network access and entity resolution. Keep this behavior enabled when changing XML handling.
